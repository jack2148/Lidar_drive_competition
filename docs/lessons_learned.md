# Lessons Learned

본 프로젝트(IRO 콘 주행)를 진행하며 LiDAR를 활용한 자율주행과 로봇-센서 간의 상호작용에 대해 배운 가장 큰 교훈은 다음과 같습니다.

## 1. 작업(Task) 환경에 맞는 센서 사양 선정의 중요성
가장 뼈저리게 느낀 점은 **"미션의 지형적 특성과 센서 고유의 스펙 한계가 일치해야 한다"**는 것입니다.
- 콘 간격이 매우 좁은 협소 주행 환경에서는 최소 감지 반경(Minimum Range)이 극도로 짧거나 없는 센서를 택해야 했습니다.
- YDLIDAR G6가 가지고 있는 15cm의 측정 불가(Blind spot) 영역을 간과했다가 좁은 골목에서 로봇이 장님이 되는 상황을 겪으면서, 로봇 공학에서 **환경 조건과 센서 하드웨어 제원의 매칭**이 1차적이고 가장 근본적인 전제조건임을 깨달았습니다.

## 2. 원시 데이터(Raw Scan) 조작 및 필터링 노하우 
단순히 라이다 드라이버를 켜는 데 그치지 않고, 후방의 노이즈 값을 버리기 위해 파라미터를 통해 시야각을 조정하고, 불안정한 스캔 값들을 코드 내 필터를 사용해 1m 이상이면 무시하도록 하는 실용적인 튜닝 방법을 경험했습니다. 현실 공간의 노이즈는 복잡한 알고리즘 이전에 **관심 영역(FOV) 축소와 임계값 자르기(Thresholding)** 로 1차 방어가 가능함을 알 수 있었습니다. 

## 3. 섹터간 거리 차를 이용한 반응형 제어 (Reactive Navigation) 
복잡한 Costmap이나 SLAM 지도 없이도, 라이다 스캔 데이터를 '왼쪽', '오른쪽', '정면'으로 뭉뚱그려 거리 대푯값을 추출한 뒤, `Left - Right`의 **단순한 거리 오차(Error)를 구해서 직진 조향에(비례 제어, Kp) 섞어주는 방식**이 강력함을 배웠습니다.
이 과정으로 복잡한 경로 계획 단계 없이, 실시간 장애물 반응만으로도 로봇을 양쪽 콘의 중앙으로 항해할 수 있도록 만드는 제어 흐름(Navigation Pipeline)을 성공적으로 체득하였습니다.
